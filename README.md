# TrailHive — SaaS Nature Company

React + Vite recreation of the Figma **Site: Saas — Nature Company** landing page.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Deploy

Push to GitHub and connect the repository to Netlify or Vercel.

The project uses the Netlify-friendly Vite build command:
`node ./node_modules/vite/bin/vite.js build`

## Exact Figma exports supplied

The `src/assets/figma-reference/` folder contains the Figma exports supplied for this implementation. The `src/assets/images/` folder contains local photo crops taken from those supplied exports so the site does not depend on remote image URLs.
